Fino — made in Kazakhstan

Как опубликовать (бесплатно, через GitHub Pages):
1. Зарегистрируйтесь на github.com.
2. Нажмите «+» → New repository → имя: fino → Public → Create repository.
3. На странице репозитория: «uploading an existing file» → перетащите ВСЕ файлы и папку lib из этого архива (не сам архив) → Commit changes.
4. Settings → Pages → Branch: main, папка / (root) → Save.
5. Через 1–2 минуты приложение откроется по адресу https://ВАШ-ЛОГИН.github.io/fino/

Как установить на телефон:
• iPhone: откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
• Android: откройте адрес в Chrome → меню ⋮ → «Установить приложение».

Данные хранятся на самом устройстве. Чтобы перенести их из версии в Claude:
Настройки → Экспорт → JSON → скопируйте; в новом приложении: Настройки → Импорт → вставьте.

Фото чеков: в установленной версии чек распознаётся прямо на телефоне, без интернета.
При первом распознавании загружается модуль (~8 МБ), дальше всё работает офлайн.
В версии внутри Claude чеки читает Claude — там точнее и с разбивкой по позициям.
